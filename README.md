# js-gym

자바스크립트 메소드 연습용 레포지토리 (Repository for practicing JavaScript methods)

## 📚 Contents

This repository contains practice examples for common JavaScript methods:

### Array Methods (`src/arrayMethods.js`)
- `filter()` - Filter even numbers
- `map()` - Map to squares
- `reduce()` - Sum array elements
- `find()` - Find first element matching condition
- `every()` - Check if all elements match condition
- `some()` - Check if some elements match condition
- `sort()` - Sort array
- `flat()` - Flatten nested arrays

### String Methods (`src/stringMethods.js`)
- `toUpperCase()` / `toLowerCase()` - Case conversion
- `trim()` - Remove whitespace
- `split()` - Split string into array
- `includes()` - Check substring existence
- `replaceAll()` - Replace all occurrences
- `substring()` - Extract substring
- `padStart()` - Pad string
- `startsWith()` - Check prefix
- `repeat()` - Repeat string

### Object Methods (`src/objectMethods.js`)
- `Object.keys()` - Get all keys
- `Object.values()` - Get all values
- `Object.entries()` - Get key-value pairs
- `Object.fromEntries()` - Create object from entries
- `Object.assign()` - Merge objects
- `Object.hasOwn()` - Check property existence
- `Object.freeze()` / `Object.isFrozen()` - Object immutability
- Deep clone using JSON
- Spread operator usage
